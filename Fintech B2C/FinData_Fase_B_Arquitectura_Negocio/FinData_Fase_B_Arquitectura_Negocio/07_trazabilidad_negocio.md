# FinData Credit — Trazabilidad de Arquitectura de Negocio

## Estrategia → capacidad → proceso → GAP

| Estrategia | Capacidad necesaria | Proceso relacionado | GAP principal |
|---|---|---|---|
| Crédito rápido | Gestión digital de solicitudes | Solicitud | Captura manual → digital |
| Evaluación automática | Evaluación de riesgo | Evaluación | Análisis manual → automatizado |
| Decisiones en tiempo real | Decisión crediticia | Decisión | Decisión lenta → rápida |
| Mejor análisis de datos | Integración financiera | Consulta de fuentes | Fuentes separadas → integradas |
| Experiencia digital fluida | Gestión digital | Solicitud y notificación | Flujo fragmentado → integrado |
| Operación controlada | Trazabilidad | Todo el proceso | Evidencia limitada → trazabilidad |
