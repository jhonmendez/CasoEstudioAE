# FinData Credit — Actores y Roles de Negocio

| Actor / rol | Participación |
|---|---|
| Cliente | Solicita el microcrédito, suministra información y recibe la decisión |
| Área de Riesgo | Define y supervisa criterios de evaluación y riesgo |
| Operación de Crédito | Supervisa el ciclo operativo del crédito |
| Dirección | Define estrategia, prioridades y objetivos |
| Datos | Asegura disponibilidad y calidad de información requerida |
| Tecnología | Soporta aplicaciones, integraciones e infraestructura |
| Bancos / proveedores financieros | Proveen información o servicios mediante integraciones |
| Bureau de crédito | Provee información crediticia |
| Regulador | Establece obligaciones de cumplimiento aplicables |

## Responsabilidad transversal
La transformación no pertenece únicamente al área de tecnología. Negocio, riesgo, datos y tecnología deben colaborar para mantener alineación entre la estrategia y la operación.
