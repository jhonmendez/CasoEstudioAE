# FinData Credit — Análisis GAP de Negocio

## Propósito
Identificar qué debe cambiar para pasar del AS-IS al TO-BE.

| AS-IS | TO-BE | GAP / cambio requerido |
|---|---|---|
| Solicitud con intervención manual | Solicitud digital | Digitalizar la captura |
| Revisión manual | Validación sistemática | Definir y automatizar validaciones |
| Fuentes separadas | Fuentes integradas | Crear capacidad de integración |
| Consolidación manual | Consolidación integrada | Normalizar y orquestar información |
| Evaluación con alta intervención humana | Evaluación automatizada | Desarrollar capacidad de scoring/evaluación |
| Decisión lenta | Decisión en minutos | Automatizar el flujo de decisión |
| Trazabilidad limitada | Decisión trazable | Registrar eventos, fuentes y resultados |
| Experiencia fragmentada | Experiencia digital fluida | Integrar el flujo de cara al cliente |

## Interpretación
El GAP no representa todavía una lista de tecnologías. Representa las capacidades, procesos y comportamientos que FinData necesita cambiar.

Posteriormente, la Arquitectura de Sistemas de Información y Tecnología determinará cómo soportar estos cambios.
