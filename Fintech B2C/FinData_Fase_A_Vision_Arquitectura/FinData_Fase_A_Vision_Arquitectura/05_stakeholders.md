# FinData Credit — Stakeholders

| Stakeholder | Interés principal |
|---|---|
| Cliente | Obtener una respuesta rápida, clara y una experiencia digital simple |
| Dirección | Crecimiento, sostenibilidad y ejecución de la estrategia |
| Riesgo | Calidad, consistencia y control de las decisiones |
| Tecnología | Sistemas mantenibles, integrables y capaces de evolucionar |
| Datos | Información confiable, disponible y gobernada |
| Operación de Crédito | Flujo operativo eficiente y trazable |
| Regulador | Cumplimiento, protección de información y trazabilidad |
| Bancos / proveedores | Integraciones controladas |
| Bureau de crédito | Intercambio de información crediticia |
| Inversionistas | Viabilidad y capacidad de crecimiento |

## Compromiso
Los stakeholders no necesariamente tienen las mismas prioridades. La arquitectura busca una dirección compartida y decisiones coherentes frente a los diferentes intereses.
